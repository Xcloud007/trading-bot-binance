# Binance Futures Testnet Trading Bot

A simplified Python trading bot that places orders on Binance Futures Testnet (USDT-M).

## 📋 Requirements

- Python 3.8 or higher
- Binance Futures Testnet Account
- API Credentials (Futures permissions enabled)
- Virtual environment (recommended)
